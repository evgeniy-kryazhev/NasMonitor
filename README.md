# NAS Monitor

Кроссплатформенное приложение для мониторинга нескольких NAS с виджетами **на рабочем столе**, позади обычных окон.

**Целевые платформы:** Windows 10/11 x64, macOS Apple Silicon (arm64), macOS Intel (x64).\
**Стек:** C#, .NET 10 LTS, Avalonia UI 11.x (последний стабильный совместимый релиз), CommunityToolkit.Mvvm.\
**Первый NAS-провайдер:** Synology DSM 7.1+ (проверка реальной поддержки на устройстве).\
**Примеры целевых устройств для испытаний:** Synology DS216+II и DS1821+.

## Главное требование

Виджет — элемент рабочего стола **позади обычных окон**. Нельзя считать `Topmost=false` готовой реализацией. Работоспособность платформенных desktop-host механизмов должна быть подтверждена реальными испытаниями. Не имитировать успешную проверку и не утверждать универсальную поддержку недокументированных Win32 API.

## Desktop spike: сборка и запуск

Реализован прототип .NET 10 / Avalonia 11.3.22 с отдельными Win32/AppKit hosts,
синтетическими CPU/RAM, Manager, настройками геометрии, RU-ресурсами и темами.
Windows smoke на build 26200 подтвердил native-привязку к WorkerW. Пользователь
подтвердил drag, перекрытие окнами, Win+D, фиксацию и сохранение позиции после
перезапуска на своей Windows. Полная OS-матрица ещё открыта; macOS не запускалась.

Чтобы двигать виджет мышью, нажмите в Manager **«Перемещать виджет»**, перетащите
его левой кнопкой за свободную от desktop-иконок область и нажмите
**«Завершить перемещение»**. Для изменения размера тяните за нижний правый
уголок. Положение и размер сохраняются при отпускании. Пользователь подтвердил
resize на своей Windows; числовые поля Manager также доступны.

```powershell
dotnet build NasMonitor.slnx -c Release
dotnet test NasMonitor.slnx -c Release
dotnet run --project src/NasMonitor.App -c Release
./scripts/publish.ps1
```

## Подключения Synology DSM

По решению пользователя проверки macOS отложены, начат этап подключения DSM.
Главное окно использует **Semi.Avalonia 11.3.22** и боковую навигацию:
**«Виджет»** — размещение/размер/фиксация; **«Подключения DSM»** — профили NAS.
Под вкладками показан список сохранённых NAS. Выбор, повторный клик или Enter
открывает форму соответствующего устройства; список обновляется после CRUD.
Светлая, тёмная и системная темы выбираются в нижней части боковой панели.
На странице виджета доступны название, пикер акцентного цвета и HEX-поле, непрозрачность 35–100%,
скругление 0–32 DIP, отдельная светлая/тёмная тема и выбор CPU/RAM/времени.
Предпросмотр обновляется сразу при вводе. «Применить внешний вид» сохраняет настройки
и обновляет desktop-виджет, «Сбросить внешний вид»
возвращает стандартные значения. Внешность сохраняется в `DesktopSpike/appearance.json`
независимо от положения и профилей NAS.

Добавьте профиль с HTTPS-адресом DSM и портом, именем пользователя и паролем.
Кнопка «Проверить соединение» отдельно показывает DNS, TCP, TLS, discovery,
авторизацию, объявленные API и выход из временной сессии. Поддержан ввод OTP.
Несколько профилей сохраняются независимо. Пароль запоминается только по выбору
пользователя в Credential Manager / Keychain; OTP и сессия не сохраняются.
Внешний адрес выбирается явно, без автоматического переключения после ошибки.

Виджет получает реальные **CPU, RAM, заполнение хранилища, сеть ↓/↑,
температуру и время работы**. Сохраните профиль и нажмите «Подключить виджет».
Если пароль не сохраняли, после сохранения профиля введите его повторно;
при 2FA добавьте актуальный OTP. На странице «Виджет» можно выбрать источник NAS.
Для каждого NAS работает один общий сборщик: ресурсы — раз в 10 секунд,
системные данные и тома — раз в 60 секунд. Ручное обновление запрашивает все группы.
Включённые профили с сохранённым паролем возобновляют опрос при запуске.
После ошибки пароля/2FA нужен явный повторный вход; OTP не переиспользуется.

Настройки разделены на вкладки «Внешний вид» и «Расположение».
Высота desktop-виджета изменяется вручную, минимальное значение рассчитывается
по видимому содержимому. Увеличенный размер сохраняется; при добавлении показателей
окно вырастает, если требуется. Предпросмотр имеет естественную высоту.
Отсутствующие, запрещённые или устаревшие метрики отображаются как «—»,
причина доступна при наведении на показатель в предпросмотре.
Без NAS показано пустое состояние; **DEMO используется только в `--smoke-test`**.
Реальный DSM, минимальные права и macOS пока **Unverified**.

## Публикация одним файлом

`./scripts/publish.ps1 -Runtime win-x64` создаёт **`artifacts/NasMonitor-win-x64.exe`** —
один self-contained исполняемый файл, включая .NET runtime и native dependencies.
Установка .NET и соседние DLL не требуются; runtime извлекает native libraries при
запуске в свой системный временный каталог. Настройки по-прежнему сохраняются
в LocalApplicationData, а секреты — в системном хранилище.

Промежуточная папка: `artifacts/publish-single-file/<rid>`.
macOS получает `.app` с одним bundled executable и обязательным Info.plist;
сборки по-прежнему не подписаны и не проверены на macOS.
