# Сообщение для вставки в Codex

Продолжаем проект NAS Monitor. Ты находишься в корне переданного репозитория.

Прочитай `AGENTS.md`, `README.md`, все файлы в `docs/` и `tasks/01-DESKTOP-SPIKE.md`.

Без дополнительных уточнений приступай к задаче 01: создай собираемый .NET 10 + Avalonia прототип виджета NAS, размещаемого как элемент рабочего стола **за обычными окнами**, с изолированными платформенными адаптерами для Windows/macOS. НЕ считать `Topmost=false` выполнением требования. Используй только тестовые метрики — подключение к Synology будет следующим этапом. Выполни сборку и доступные тесты. Для платформ, которые не можешь запустить, предоставь инструкцию ручной проверки и честно отметь статус как Unverified. Обнови документацию и отчитайся по файлам, результатам и ограничениям.
