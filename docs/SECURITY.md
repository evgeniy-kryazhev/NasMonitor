# Security baseline

- Windows: OS credential store (Credential Manager) с секретом на профиль NAS.
- macOS: Keychain; проверить entitlement/access-group требования выбранного distribution method.
- Профили: только неперсональные параметры и opaque secret reference.
- HTTPS включён по умолчанию, нормальная проверка цепочки сертификата и hostname. Для self-signed NAS нужен явный безопасный workflow доверия (например, pinning fingerprints с предупреждением и подтверждением), не глобальное `DangerousAcceptAnyServerCertificateValidator`.
- 2FA: краткоживущий одноразовый код не сохранять.
- API tokens, cookies, passwords, session IDs должны быть редактированы из логов.
- Least privilege: тестировать доступность метрик для DSM user без администраторских прав. Недоступность отдельных метрик не должна ломать остальные.
- Не выполнять операции изменения NAS в V1.
- Не хранить секреты в проекте/AGENTS.md/конфигах образцов; test fixtures только синтетические.

## Подключение DSM — реализованный срез

- Авторизация только через HTTPS origin, без credentials/query/subpath в URL.
- HttpClientFactory: cookies и automatic redirects отключены, HTTP logging удалён.
- Пароль, OTP и SID передаются в POST body; CSRF — в заголовке X-SYNO-TOKEN
  конкретного запроса, без DefaultRequestHeaders. URL не содержит секретов;
  нет логирования запросов/заголовков/ответов/исключений.
- Discovery path ограничен относительным /webapi/ внутри того же origin.
- Пароль опционально хранится OS-secret-store под случайным UUID. При смене
  endpoint/username старый пароль не используется для новой идентичности.
- OTP и SID не сохраняются. Проверка делает logout даже при отмене/ошибке после входа,
  с отдельным 5-секундным лимитом; отказ logout явно виден в результатах.
- При уходе со страницы и закрытии приложения секретные поля очищаются.
  Управляемые string нельзя гарантированно стереть из памяти; длительный секретный
  кэш не создаётся. Буферы, выделяемые adapters, очищаются там, где это возможно.
- Запись профилей атомарна, версия схемы проверяется. Повреждённый/новый формат
  не перезаписывается. При отказе удаления старого OS-secret возможен оставшийся
  зашифрованный item; UI сообщает, что операция могла завершиться частично.
- Pinning self-signed сертификатов пока не реализован; такой сертификат отклоняется.

## Мониторинг DSM

- Постоянные сессии сохраняют в памяти только SID/CSRF; пароль повторно читается
  из OS store только для входа. Несохранённый пароль не кэшируется для reconnect.
- OTP используется один раз. Ошибка пароля/2FA останавливает автоматические
  попытки; истечение SID допускает один повторный вход из OS store.
- Профили с несохранённым паролем требуют ручного входа после перезапуска.
- При удалении/изменении профиля и при shutdown pollers отменяются и ожидаются;
  logout best effort с отдельным лимитом 5 секунд. Отказ logout не логирует SID
  и не считается подтверждённым выходом; сервер завершит сессию по своей политике.
- Метрики только читаются: get/info/load_info. Нет методов изменения NAS.
- Имена/пути/API версии проверяются; partial permission denied остаётся
  свойством конкретного показателя и не выдаётся за реальный ноль.
