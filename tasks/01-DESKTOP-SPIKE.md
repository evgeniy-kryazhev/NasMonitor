# Задание Codex 01: Desktop Widget Technical Spike

## Цель
Проверить в коде работоспособность единой Avalonia desktop-widget UI на Windows 10/11 и macOS Intel/Apple Silicon, с отдельными Win32 и AppKit адаптерами.

## Реализация
1. Создать решение .NET 10 с Avalonia (последняя стабильная версия, поддерживающая .NET 10), DI, MVVM и минимальной модульной структурой.
2. Сделать тестовый widget view: название NAS, status, CPU/RAM, last-update; синтетические данные, НЕ реальные логины/API.
3. Сделать interface для desktop host и реализации Windows/macOS, ограничить платформенный код узкими проектами.
4. Реализовать привязку к desktop layer либо документировать блокирующие ограничения конкретного механизма. Не смешивать `Topmost=false` с desktop host.
5. Уметь открыть Manager/control window, переключить edit/locked, переместить виджет и сохранить координаты и размер (если разрешает shell).
6. Писать диагностические логи без персональных данных.
7. Создать протокол ручной проверки с матрицей OS/version/features; автоматизировать тесты доменной логики.
8. Сборки Windows x64 и macOS arm64/x64, насколько позволяет среда Codex. Если среды ОС нет, написать 'not tested' и дать инструкции.

## Критерии готовности
- `dotnet build` успешен в доступной среде.
- Данные обновляются без DSM.
- Виджет реально за обычными окнами на проверенной ОС, не появляется поверх приложений при клике.
- Не считается готовым для ОС, где отсутствует ручная проверка.
- Есть тестовый чек-лист для Windows и macOS, результаты, описанные риски, будущий план исправлений.

## Твой первый ответ пользователю в Codex
Коротко изложи план, затем приступай к созданию рабочего кода без запроса повторного ТЗ. По окончании сообщи фактические результаты и что пользователь должен проверить на своём Windows/macOS.
